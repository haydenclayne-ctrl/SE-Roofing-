# Logos

The SE Roofing logo family and usage rules.

## Files to add

- [ ] Primary logo (full color) — vector source (`.ai`/`.eps`/`.svg`) + exported `.png`
- [ ] Reversed/white version (for dark backgrounds)
- [ ] Monochrome/black version
- [ ] Icon-only / mark (if one exists, for favicons, social avatars)

Suggested naming: `se-logo-primary.svg`, `se-logo-reversed.svg`, `se-logo-mono.svg`, `se-logo-icon.svg`.

## Usage rules (fill in once defined)

- **Clear space**: minimum padding around the logo — TBD
- **Minimum size**: smallest the logo should ever be reproduced at (print & digital) — TBD
- **Backgrounds**: which logo version to use on light vs. dark vs. photo backgrounds — TBD
- **Don'ts**: no stretching, recoloring, rotating, adding effects (drop shadows, outlines), or placing on busy backgrounds without sufficient contrast

## Approved file formats

| Use case | Format |
|---|---|
| Web | `.svg` (preferred), `.png` (fallback, transparent background) |
| Print | `.eps` / `.pdf` (vector) |
| Editing source | `.ai` / `.fig` (kept here for future edits, not for distribution) |
