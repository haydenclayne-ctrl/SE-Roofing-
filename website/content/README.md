# Website Content Guidelines

Copy conventions and content standards specific to the SE Roofing website (as distinct from general brand voice, which lives in [`brand/voice-and-messaging`](../../brand/voice-and-messaging)).

## Confirmed from the live site (roofingse.com)

- **Headline**: "COMMERCIAL ROOFING YOU CAN COUNT ON"
- **Taglines**: "Built by roofers. Powered by our crews." / "Trained Crews. Proven Materials. Guaranteed Results." — site-only for now, see [`brand/voice-and-messaging`](../../brand/voice-and-messaging) open item
- **Services listed**: Commercial Roofing · New Construction · Overlay & Restoration · Tear Off & Replacement
- **CTA phrasing in use**: "Learn More" · "Get In Touch" · "Contact Us" · "View All" / "View Project" (for the projects section)
- Site currently shows "1+" placeholders for stats (roofs installed, states served, years experience) — worth updating with real numbers when available.
