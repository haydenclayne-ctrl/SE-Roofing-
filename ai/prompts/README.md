# Prompt Templates

Reusable prompts for generating on-brand SE Roofing content with AI tools. Each prompt should assume the reader has (or is given) `ai/brand-brief.md` as context.

## Suggested starter set (add as `.md` files here once needed)

- `social-caption.md` — generate a social media caption for a given topic/campaign
- `service-page-copy.md` — generate service-page paragraph copy for a given roofing service
- `ad-copy.md` — generate short-form ad copy (headline + body) for digital/print ads
- `email-followup.md` — generate a customer follow-up/estimate-reminder email
