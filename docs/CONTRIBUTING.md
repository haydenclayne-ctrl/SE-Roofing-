# Contributing to this repo

This repo is the single source of truth for SE Roofing's brand. A few ground rules to keep it that way:

1. **New asset → update the folder's README.** Every folder's `README.md` lists what should be there; if you add a file, note it (check off the relevant `- [ ]` or add a row).
2. **Naming**: lowercase, hyphen-separated, no spaces or version cruft (`se-logo-primary.svg`, not `Final_Logo_v2 (1).svg`).
3. **Source + export together**: when a file has an editable source (`.ai`, `.psd`, `.fig`, `.indd`) and a final export (`.pdf`, `.png`, `.svg`), keep both, and make clear which is which.
4. **Big changes to brand fundamentals** (logo, color palette, core messaging) should get a PR/review rather than a direct push, since downstream marketing and website work depends on these staying stable.
5. **AI-facing docs** (`ai/brand-brief.md`, `ai/prompts/`) should stay in sync with `brand/` and `marketing/playbook/` — if you change a messaging pillar or a color, check whether the AI brief needs updating too.
