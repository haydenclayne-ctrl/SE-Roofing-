# Campaigns

Assets and briefs for specific, time-bound marketing campaigns (as opposed to evergreen assets, which live in [`marketing/assets`](../assets)).

## Structure

One subfolder per campaign, e.g.:

```
marketing/campaigns/
├── 2026-spring-storm-season/
│   ├── brief.md
│   └── assets/
└── 2026-referral-program/
    ├── brief.md
    └── assets/
```

Each `brief.md` should capture: goal, target audience, offer, channels, dates, and a link back to the relevant messaging pillar in [`brand/voice-and-messaging`](../../brand/voice-and-messaging).
