## Organization

Group by type as the collection grows, e.g.:

```
marketing/assets/
├── print/        # door hangers, flyers, yard signs
├── digital-ads/  # social/display ad creative
├── one-pagers/   # sell sheets, service overviews
└── templates/    # editable source templates for the team to reuse
```

Keep editable source files (`.psd`, `.ai`, `.indd`, `.fig`) next to their final exports (`.pdf`, `.png`, `.jpg`), or in a parallel `source/` subfolder if that's cleaner — note the choice here once the collection grows past a couple of files.
